# research/

Working notes and downloaded sources for the paper (see `.cursor/rules/research-sources.mdc`).

- `research/<topic>.md`: our own notes (derivations, tests, decisions). Copied to the public snapshot.
- `research/<citekey>/`: a downloaded paper (arXiv source, extracted text). Never copied to the public snapshot.
- `research/review<N>.md`, `research/response<N>.md`: referee reports and responses. Never copied to the public snapshot.
